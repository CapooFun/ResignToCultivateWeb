## 摘要

竖屏手机网页修仙肉鸽 Demo：洞府备战 → 小/中/大地图格子探索 → 格上 CD 自动战斗 → 回府或死亡轮回。

**公开试玩**: https://capoofun.github.io/ResignToCultivateWeb/  
**仓库**: https://github.com/CapooFun/ResignToCultivateWeb

## 已通过验收

- `npm run check`：14 项核心/存档/地图测试通过，TypeScript 与生产构建通过。
- 地图生成：S/M/L 各 100 个 seed；逐层验证尺寸、传送门数量和关键点连通性。
- `npm run test:e2e`：生产包共 7 项通过、1 项按条件跳过；覆盖桌面 Chromium、iPhone 15 尺寸移动 WebKit、PWA 清单与 Service Worker。
- Chromium 首次联网后断网刷新，仍可进入洞府；Playwright WebKit 的离线网络模拟会触发内核错误，因此 iOS 离线冷启动仍保留给真实 iPhone 15 验收。
- 393×852 窄屏人工试玩：洞府 → 选择 S 地图 → 键盘移动 6 步 → 遭遇山狼 → CD 自动施法 → 胜利 → 刷新续玩。
- 浏览器运行日志：无 error / warn。
- 修复：动画完成回执被渲染更新取消；React StrictMode 下 WebKit 重复挂载 Phaser 画布。
- 视觉：宣纸/松墨/朱砂体系、地形纹理、符印、CD 圆环、战斗横幅、1200×630 分享图。
- GitHub Pages 子路径构建验证通过（manifest / SW / 图标 / 分享图均带仓库前缀）。
