**阶段**: Demo（非正式版）  
**版本**: v0.1.0 · SAVE **v3** / CONTENT **v6** / GENERATOR **v5**  
**最后更新**: 2026-08-04  
**权威边界**: 玩法意图以 Infans_Vault「辞职修仙传」为准；本文件只描述**当前工程已落地**的规则，会随 Demo 迭代改动。

## 1. 核心循环

```
洞府整备 → 选图(S/M/L) → 格子探索 / 格上 CD 战斗
    → 回府沉淀｜寿元耗尽或战败 → 轮回点（三选天赋强化）→ 转世回洞府
```

- 洞府设施 UI 顺序：**采矿 → 炼丹 → 炼器 → 仓库**；另有装配与行囊、设置（含静音）。
- 探索：点击相邻格 / 滑动 / WASD；回府阵字「回」、深层「传」。
- 战斗：连续时间 CD；普攻按攻速；已装配秘术按优先级自动施放；腰带丹药手动排队；可尝试逃跑。

## 2. 洞府与采矿

| 玩法 | 落地规则 |
|------|----------|
| 回府待收 | 本趟消耗寿元 × `mineYieldPerYear(等级)` 累计到 `mineStored`，再「收取灵石」 |
| 叩击灵脉 | 打开采矿面板，点晶核：耗 **1 灵息**，灵石进**待收**；点下方大数字统一收取（金币哗啦啦音效）；小概率**爆发** |
| 手机锁定 | 禁页面拖拽/双击缩放；切后台或锁屏暂停音频 |
| 灵息 | 随时间回复；等级越高上限越高、回复越快（见数值文档） |
| 并行 | 手动叩击与回府年产**并行**，互不替代 |
| 炼丹 / 炼器 | 材料可从身上 + 仓库共扣；产物入库；设施等级锁配方 |
| 仓库 | 与行囊互转；容量可升级/作弊扩容 |

细节 UI：独立 `MinePanel`（晶核回弹、火花、飘字、共鸣）。

| 项 | Demo 现状 |
|----|-----------|

## 4. 探索与地图

- 三档：青石谷(S) / 云梦泽(M) / 太玄山(L)；合计 **6 全局难度层**
- 地形：平原、林、水、山（噪声生物群落）；水需筑基、山需结丹方可进入
- 迷雾：随境界扩大揭示半径与可视窗；未揭示格不显示实体
- 实体：敌（普通/精英/首领）、灵材、灵泉（回满一次后消失）、秘境、回府、深层传送
- 敌人 18，按层分池；面板与掉落按层指数拉开（见数值文档）

## 6. 战斗与逃跑

| 项 | 规则 |
|----|------|
| 基础逃跑率 | 50%，上限 95% |
| 加成 | 鞋子成功率 + 天赋「遁术」每级约 +3% + **本次**遁药 `nextEscapeBonus` |
| CD | 基础 20s；鞋子减免，最终下限 4s |
| 丹药复合 | 可同时含回血 / 回灵 / 逃跑加权；战斗统一结算 |
| 动画锁 | 有超时 failsafe，避免动作卡住 |
