## 2. 品质外框

- 工具：`qualityCssClass(quality)` → `q-*`（`content.ts`）
- 容器加类：`quality-frame q-…`（2px 色边 + 轻 inset）
- **已挂载**：行囊/仓库 stack、法宝六槽与可装列表、炼丹炼器配方、秘术/心法列表、丹药腰带槽、探索 HUD 丹药钮、轮回天赋卡

文案同时显示品质名（如 `灵宝 · ×3`），外框负责「一眼扫货」。

## 3. 已落地界面要点

| 界面 | Demo 约定 |
|------|-----------|
| 洞府 | 设施顺序：采矿 → 炼丹 → 炼器 → 仓库；装配入口；设置（静音）；**风灵月影**测试钮（弱样式） |
| 采矿 | 独立 `MinePanel`：矿洞暗室 + 灵脉晶核点按；飘字/火花/冲击波/共鸣；爆发走 `RewardPopup`；灵息条与等级收益提示 |
| 装配与行囊 | 分栏：全部 / 法宝 / 灵材 / 秘术 / 心法 / 丹药；法宝 3×2 六槽（上：近战/远程/护甲；下：**戒指/腰带/鞋子**）；秘术点按装配；品质外框 |
| 探索 HUD | 非战斗点中栏血蓝条打开行囊装配；战斗中不可开。丹药钮 +「逃」。底栏贴探索区底，不重复叠加 safe-area |
| PWA 引导 | 第一次死亡并点「转世」回洞府后弹出「添加到主屏幕」；已 standalone / 已看过不再弹 |
| 地图 | 回府「回」、深层「传」；迷雾未揭示暗色；探索区尽量铺满可视区域 |
| 轮回点 | **只展示本次 3 个可选天赋**，不可浏览全部 12；天赋卡带品质外框 |
| 弹层 | `position: fixed`，避免面板滚出视口 |
| 音频反馈 | 场景 BGM 切换；点击/移动/胜负/逃跑/弹窗 SFX（可静音） |
