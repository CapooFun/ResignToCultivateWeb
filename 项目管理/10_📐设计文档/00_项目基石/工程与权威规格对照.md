## 技术栈

React 19 + Phaser 3 + TypeScript + Vite + IndexedDB + PWA（`vite-plugin-pwa`）

规则在纯 TS；Phaser / React 只渲染与派发命令。音频：`src/game/audio.ts` + `public/audio/`。
