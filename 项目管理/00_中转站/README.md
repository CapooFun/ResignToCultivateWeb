# 中转站

**最后更新**: 2026-08-04

本目录存放**未定稿**过程文档：AI 审查报告、方案草稿、问题分析、实施总结、一次性讨论稿等。

> 原名「临时工作站」；本项目起统一称 **中转站**——东西从这里过，结案后升格、归档或清理。

## 规则

1. AI 生成的长文、方案、审查稿优先放此处，避免与 `10_📐设计文档/` 定稿混淆。
2. 结案后三选一：
   - **升格** → 移入 `10_📐设计文档/` 对应层
   - **备查** → 移入 `0_0制作人工作台/99_🗑️垃圾箱/`
   - **删除** → 不再需要
3. 可按日期建子目录（如 `2026-08-04/`），结案后清空或只留索引。

## 流转

```
草稿 / 审查 / 讨论
        ↓
   00_中转站/
        ↓
  升格 | 垃圾箱 | 删除
```
