# 手动采矿：叩击灵脉

**日期**: 2026-08-04  
**状态**: 已落地（content v6；交互续改）  
**目的**: 把洞府采矿做成核心吸量交互——点按有反馈、有概率爆发、升级明显变强。

## 玩法

- 打开「采矿」→ 矿洞暗室中央的**灵脉晶核**
- 每次叩击消耗 1 **灵息**，灵石进入下方 **待收**（不立即入库）
- 点「待收灵石」大数字统一收取；播放金币哗啦啦音效（`coin-cascade.wav`，取材 Mixkit casino coins 预览裁剪）
- 小概率 **灵脉爆发**（奖励弹窗 + 强化特效）；爆发量同样进待收
- 矿场等级越高：普击区间、爆发区间、爆发率、灵息上限与回复速度全部提升
- 原有回府待收年产保留，与手动并行（都进 `mineStored`）

## 手机手感

- 页面锁定：禁左右拖、禁双指/双击缩放（viewport + `touch-action` + gesture 拦截）
- 采矿面板打开时 `body.mine-lock`，晶核区 `touch-action: none`
- 切后台 / 锁屏 / 隐藏页签：音频 `suspend`；回前台再 `resume`（尊重静音开关）

## 数值入口

`manualMineStrikeTable` / `mineBreathMax` / `mineBreathRegenMs`（`content.ts`）
