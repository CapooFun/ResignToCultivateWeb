## 采集字典（客户端会上报什么）

### 事件

| 事件 | 何时 | 用途 |
|------|------|------|
| `session_start` | 打开游戏 | 活跃、设备、当前进度快照 |
| `run_start` / `run_end` | 出发 / 回府 | 趟数、步数、层数、图档 |
| `floor_advance` | 下楼 | 推图深度 |
| `combat_win` / `combat_flee` | 战斗结算 | 难度、逃跑依赖 |
| `death` / `reincarnate` | 寄了 / 转世 | 流失点、轮回循环 |
| `craft` | 炼制成功 | 洞府参与度（丹/器分流） |
| `upgrade_facility` | 升级设施 | 养成投入 |
| `buy_talent` | 买天赋 | 轮回构建 |
| `discard` | 丢弃物品 | 背包压力是否真实 |
| `mine_collect` | 收灵石 | 采矿循环 |
| `cheat_on` / `cheat_off` | 风灵月影 | 测试污染标记 |
| `milestone` | 首次达成某成就 | 漏斗与噱头 |
| `session_summary` | 切后台 | 时长与阶段进度 |

### 累计 stats（跟在每条上报里）

会话、探索、回府、死亡、转世、胜/逃、精英/Boss、炼制（丹/器）、设施升级、买天赋、丢弃、采矿收取、风灵月影开关、游玩时长、单趟最长步数、最深层、图档计数、巅峰境界、秘术/心法峰值、因果/灵石峰值、里程碑列表、设备粗画像。

### 设备字段（隐私克制）

只报：`os` / `form` / `touch` / `standalone` / `screen` / `lang` / `tz`。  
**不报**：精确机型名、完整 UA、IP（IP 只存在于 Cloudflare/Discord 基础设施，我们自己不存库）。

### 如何从 Discord 汇总「多少人 / 多少设备」

1. 导出或翻频道消息里的 `玩家 \`p_xxxx\``  
2. **玩家数** = 不同 `playerId` 个数  
3. **设备触点数** = 不同 `os/form/screen` 组合个数（同一人换手机会变）  
4. **污染样本**：带里程碑 `cheat_used` 的玩家，分析正式难度时可单独剔除或标注
